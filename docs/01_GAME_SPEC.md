# BEAT ON STAGE ゲーム仕様 v1.0

2026-10-29。企画決定と開発用の仮設定を区別する。本ZIPに実装済みゲームや完成譜面は含まれない。

## コンセプトと公開方針

名称：BEAT ON STAGE（ビート・オン・ステージ）。説明：ミスヘブン総選挙 非公式応援リズムゲーム。
応援する人が短いライブを楽しみ、自分や推しのキャラで繰り返し遊べるゲーム。ゲーム性、音と操作の一致、楽しい譜面、読みやすさを優先する。豪華な演出は負担が小さい範囲で追加。
専用サイトを新設し、完成後にゆず係サイトからリンクする。全員共通のサイト内でキャラを選び、キャラ別専用リンクは作らない。既存ゆず係サイトへゲームを埋め込む構成ではない。

## 遊びと画面

- スマホ縦持ち。上からノーツが落ちる4レーン。親指2本を基本としPCはD/F/J/K。
- 操作はタップと長押し。同時押しは最大2か所。フリック・スライドは初期版対象外。
- EASY／NORMAL／HARD。レーン数は共通で、ノーツ密度・リズム・配置を変える。
- ミスが続いても最後まで遊べる。ライフ切れによる強制終了なし。
- 曲選択→キャラ選択→難易度→プレイ→結果。設定は選曲やプレイ準備から開く。
- 初回のみ短い操作練習、スキップ可能。既定はゆずちゃん・EASY、前回の有効な選択を保存。第1段階はNORMALのみ実装するため、既定もNORMALへ一時変更する。
- 再生前に短いカウントダウン。音源の前にノーツ表示の準備時間を置ける設計とし、原曲のイントロを削らない。
- 一時停止、最初から、選曲へ戻る。タブ離脱や端末割込み時は適切に止め、勝手に復帰させない。

## 判定とスコア

判定はPERFECT／GREAT／GOOD／MISS。早い・遅い表示は切替可能。満点100万点。コンボは倍率に使わず、記録と控えめな演出に使用。
自己ベストは曲ID・難易度・譜面版ごとに端末内保存。キャラ変更で記録を分けない。ログイン、公開ランキング、キャラ人気ランキングは初期対象外。
結果：曲・難易度・選択キャラ・名前・スコア・自己ベストとの差・最大コンボ・判定内訳。1タップで同条件リトライ。自己ベスト差は更新前の記録と比較する。中断したプレイは結果や自己ベストに記録しない。

開発用仮値：PERFECT ±45ms、GREAT ±90ms、GOOD ±135ms、外側MISS。配点重み1.0／0.7／0.3／0。これは未検証の初期値で、調整できる場所にまとめる。
長押しは開始と終端を各1判定単位とする仮案。継続中に別のレーンの操作を阻害しない。早離しは終端MISS、終端まで維持できたら終端成功とし、終端で指を離す正確さは要求しない。最初の取り逃しは開始・終端を各MISS。譜面の総判定単位を分母に100万点へ正規化し、満点・二重計上・空打ち加点を検証。必要なら実装時に改善し、ルール変更を記録する。

## 譜面の品質

イントロから簡単なリズムで入り、歌・サビで盛り上げる。同じフレーズに共通配置を使い、何の音を叩くか伝わるようにする。休符も作る。長押し中の操作を含め同時接触は2本まで。連続する押し分けの移動距離・速度を確認する。見づらさや不意の速度変化を難しさにしない。
フェードでほぼ聴こえない末尾に無理なノーツを置かず、最後のノーツの後に余韻を残す。オートプレイは開発確認用に用意してもよいが自己ベスト対象外。

## 見た目・素材

ライブステージ。黒〜深紫を土台に紫と明るい差し色を使う。4列の境界、ノーツ、判定線は明瞭に。色だけで区別しない。プレイ中のキャラは上部ステージに置き、ノーツと指の操作を邪魔しない。キャラが小さくても切れずに収まること。
背景はコードで照明・グラデーション・床を制作。ノーツやラインもコードで描画。初期ロゴはタイトル文字組み。ジャケットは曲名を読みやすくした共通の仮デザイン。
軽い成功発光、コンボ節目の小さな弾み、サビでの背景変化は余力があれば実装。サビ時刻が未確認なら自動で確定したふりをせず設定可能にする。ダンス、口パク、大量エフェクト、複数キャラ同時出演は後回し。強い点滅・揺れは抑え、演出軽減設定を用意。
結果画面はスクリーンショットで共有しやすくする。画像保存・X投稿連携は後回し。外部リンクはプレイ中に置かずキャラ選択・結果画面へ。

## キャラと設定

基本はchar_0001・ゆずちゃん。承認済みの基本画像だけを同梱。6ポーズの候補シートは最終承認がなく、実装素材には含めない。
出場者・応援参加者・創作キャラを同じ選択画面で扱い、名前、区分、任意の所属・紹介・Xを表示。未確認の所属・Xは空欄。本人・権利者の了承確認は運営工程。公開可否をデータで管理する。
キャラ画像制作・シート・差分・透過・切り出し・素材整理はGPT。Claudeは登録・選択・紹介表示・ゲーム演出。差分不足はidle代用。全曲で全キャラを選べ、得点などに差をつけない。
設定：ノーツ速度、タイミング補正、音楽・打音音量、早遅表示、演出軽減。タイミング補正は符号の説明と動く試聴・テストを設け、実際に判定にも反映する。

## 受入基準

1. スマホ幅390pxを含む幅でキャラ・ノーツ・ボタンが切れない。
2. ユーザー操作から音源が鳴り、音とノーツが終盤まで大きくずれない。実機で未確認ならその旨を記録する。
3. 2点タップ、長押し＋別レーン、PCキーが動く。押しっぱなしで同じノーツが何度も加点されない。
4. 判定境界・満点・MISS・長押しの取り逃し・早離しを意味のあるチェックで確認。
5. 終了後に結果が1回だけ表示され、自己ベストが正しく残り、即リトライで音声・ノーツ・入力が重複しない。
6. 一時停止・復帰、タブ離脱、選曲へ戻る、再生失敗が破綻しない。
7. 画像を読み込めない場合にも操作不能にならない。個人情報・架空のリンクを公開しない。
8. 試作段階の未確認箇所、譜面の仮状態、実機確認の有無を明記する。
