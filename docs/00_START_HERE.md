# BEAT ON STAGE — Claude Code 開発開始指示

あなたはこの音ゲーの専任開発担当です。添付ZIPを展開し、docs/01_GAME_SPEC.md、docs/02_HANDOFF.md、docs/03_CHARACTER_WORKFLOW.mdを読み、まず第1段階の試作を実装してください。企画をもう一度最初から質問し直さず、確定事項を守って判断可能な実装を進めてください。

## 今回完成させる範囲

「Vote Vote Vote／NORMAL／ゆずちゃん」で、曲選択→キャラ選択→難易度→プレイ→結果→即リトライまで動くスマホ縦持ち4レーン音ゲー。

音源はassets/audio/vote.mp3、キャラはassets/characters/char_0001/idle.pngを使用。キャラ画像の再生成・衣装変更は不要。曲の冒頭とテンポを維持すること。2曲目も同梱しているが、第1段階では開発範囲を広げない。未実装の曲・難易度は押せるふりをせず準備中表示または非表示。

## 開発順序

1. 作業先と既存ルールを確認。専用の独立プロジェクトで進め、既存ゆず係サイトは変更しない。既存環境があれば尊重し、なければReact＋TypeScript＋Viteを第一候補にする。
2. 音源を実際に調べてBPM・拍頭・必要ならテンポ変動を確認し、NORMAL譜面を制作する。仮譜面は仮と明示し、等間隔のノーツを並べただけで完成としない。音源を聴く機能がない場合は制約を報告し、解析で判断できたことと未確認のことを分ける。
3. 曲・キャラ・譜面をデータとして分離。キャラと曲が独立して選べる構造にする。
4. 同期・入力・判定・長押し・結果集計を先に完成。背景はコードで軽いライブステージにする。
5. スマホ幅とPCで一連の動作を検証。途中停止、非アクティブ復帰、即リトライも確認。
6. 実装済み／仮／未実装、確認できた環境と未確認の実機事項、起動方法、次の作業をHANDOFF.mdに記録して報告。

## 守ること

- 4レーン、タップ＋長押し、最大2点同時押し。親指2本で無理なく遊べる配置。
- 音声の再生時刻を基準にし、フレーム数やタイマー積算を譜面時刻の基準にしない。
- 曲はユーザー操作で開始。再生失敗は表示し、黙ってゲームだけ進めない。
- マルチタッチとD/F/J/Kに対応。スクロールや拡大と競合しないようプレイ領域を設計。
- キャラの元写真・連絡先・了承記録を公開物に含めない。X URLや所属を捏造しない。
- 絵の差分制作・キャラシートはGPT担当。素材不足はidleで代用して開発を止めない。
- 派手な演出のために同期・視認性・動作安定を犠牲にしない。
- タイトルは非公式企画。名前の重複確認、公開先URL、リンク先URLは未確定事項として引き継ぐ。
- この依頼は試作実装まで。公開・ドメイン購入・外部サービス契約・ゆず係へのリンク設置は別工程。

必要な質問は、既存リポジトリ選択など作業が分岐して判断不能なものに絞ってください。変更可能な数値は設定にまとめ、合理的な仮値で進めてください。
